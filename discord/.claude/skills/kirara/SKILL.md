このガイドでは、kirara上でキャラクターを設計する手順を説明します。
kiraraとは、LLMがUtility AIを設計するためのフレームワークです。

# キャラクター設計
キャラクター設計は、主に2ステップに分けられます。

1. 内部パラメータの定義
2. 内部パラメータ変化式の定義
3. 内部パラメータによるアクションの定義

# 行動ガイド
内部パラメータ定義を行う前に、あなたにどのようなイベントが入ってくるかを確認してください。
あなたに流れてくるイベント/あなたが実行可能なActionは、プロンプトに渡されたファイルパスにあるconfigファイルに記載されます。
必ず確認して、そこにないイベント/Actionは使用しないでください。

内部パラメータの定義方法については、Params SKILLを参照してください。
内部パラメータ変化式をTransitionsと呼びます。Transitionsの定義方法については、Transitions SKILLを参照してください。
内部パラメータの値から行動を決定するAction定義の方法については、Action SKILLを参照してください。
キャラクターのTransitionsやActionスコア決定式ではmathjsを使用します。
mathjsの式の書き方、また応答曲線の設計方法については、Curve SKILLを参照してください。
できるだけ線形で単調なものよりも、複雑な曲線を使用するようにしてください。

設計したパラメータとトランジションを単一設定ファイルに保存します。
tickは推奨500 ~ 1000msです。
```yaml
version: "0.1.0"
description: "説明文"
tick: Utility AIのループ周期(数値型で単位はms 500~1000推奨)

params:
transitions:
actions:
```

# 注意
入力となるイベントに、定義されていないものを使用しないでください。
あなたに与えられたSKILLに定義されていないプロパティを追加することを禁止します。

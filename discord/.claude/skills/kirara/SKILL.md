kiraraは、LLMがキャラクターの内面をUtility AIとして設計・運用するフレームワークです。

# 設計フロー

以下の順序で設計してください。

1. ユーザーに、キャラクターにどのような行動をさせたいかを尋ね、具体的なaction名として例示する
2. 外界からどのようなイベントがどのようなスキーマで来るかを尋ねる
3. キャラクター資料を読み込み、性格・行動傾向・感情パターンを分析する。場所がわからなければ尋ねる
4. キャラクターの内面を表現するパラメータを設計する(Params SKILL参照)
5. パラメータの変化式を設計する(Transitions SKILL参照)
6. Actionのスコア式を設計する(Actions SKILL参照)
7. YAMLをユーザーに提示・ユーザーが指定したパスに保存する
8. simulate_characterツールを使って、シミュレーション結果を取得
9. 自分で満足がいくまで改善する
10. 満足がいったら必ずビジュアライズしてユーザーに提示・ユーザーのフィードバックを求める

# configファイルの確認

# 保存フォーマット

```yaml
version: "0.1.0"
description: "キャラクター説明"
tick: 500~1000

params:
transitions:
actions:
```

tickはms単位。500~1000を推奨。

# 禁止事項
- ユーザーから与えられていないイベントの使用
- SKILLに定義されていないプロパティの追加

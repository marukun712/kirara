# Utility AI — 応答曲線リファレンス

> **前提**: 入力 `x` は `0〜1` の正規化済み値。出力も `0〜1` を返す。  

---

## 1. Linear

値に比例してスコアが上がる。最もシンプル。

```
"x"
```

---

## 2. Polynomial

傾きを非線形に調整する。`k` で急峻さを変える。

```
"x ^ 2"

"x ^ 3"

"sqrt(x)"

"x ^ k"
```

---

## 3. Sigmoid

中間で急激に変化、両端は安定。`k` で傾きを制御。

```
"1 / (1 + exp(-k * (x - 0.5)))"
```

---

## 4. Exponential

初期は緩やか、末尾で急上昇。

```
"(exp(k * x) - 1) / (exp(k) - 1)"
```

---

## 5. Logarithmic

初期で大きく上昇し、その後は横ばいになる。

```
"log(1 + x * (e - 1))"
```

---

## 6. Sine

中間でピークを持つ山型。

```js
"sin(pi * x)"

"(1 - cos(pi * x)) / 2"
```

---

## 7. Step

閾値を境に 0/1 で切り替える。

```
"x >= t ? 1 : 0"

"x < t ? 0 : (x - t) / (1 - t)"
```

---

# 曲線設計のチェックポイント

- キャラクター性を反映できていますか?
複雑な曲線を使用することは効果的ですが、それがかえってキャラクター性を失ってしまうと意味がありません

- 人間はその行動をできますか?
キャラクター性を重視するあまり、人間には難しいペースで行動してしまうなど

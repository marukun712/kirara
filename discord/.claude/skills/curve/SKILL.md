# Utility AI — 応答曲線リファレンス

> **前提**: 入力 `x` は `0〜1` の正規化済み値。出力も `0〜1` を返す。  

---

## 1. Linear（線形）

値に比例してスコアが上がる。最もシンプル。

```
"x"
```

| x   | 出力 |
|-----|------|
| 0.0 | 0.0  |
| 0.5 | 0.5  |
| 1.0 | 1.0  |

---

## 2. Polynomial（多項式）

傾きを非線形に調整する。`k` で急峻さを変える。

```js
// 二次（遅い立ち上がり）
"x ^ 2"

// 三次
"x ^ 3"

// 平方根（速い立ち上がり）
"sqrt(x)"

// 汎用：k < 1 で凸、k > 1 で凹
"x ^ k"   // k = 2 など
```

---

## 3. Logistic / Sigmoid（S字曲線）

中間で急激に変化、両端は安定。`k` で傾きを制御。

```js
// 標準シグモイド（x=0.5 を中心に）
"1 / (1 + exp(-k * (x - 0.5)))"   // k = 10 など

// 0〜1 に正規化した版
"(1 / (1 + exp(-k * (x - 0.5))) - 1 / (1 + exp(k * 0.5))) / (1 / (1 + exp(-k * 0.5)) - 1 / (1 + exp(k * 0.5)))"
```

> **用途**: 体力が一定以下になると一気に危険度が上がる、など

---

## 4. Exponential（指数）

初期は緩やか、末尾で急上昇。

```js
// 基本指数（k で傾き調整）
"(exp(k * x) - 1) / (exp(k) - 1)"   // k = 3 など
```

---

## 5. Logarithmic（対数）

初期で大きく上昇し、その後は横ばいになる。

```js
"log(1 + x * (e - 1))"
```

> **用途**: 最初の距離はすごく重要だが、遠くなるほど差が縮まる場合など

---

## 6. Sine（サイン波・ベル型）

中間でピークを持つ山型。

```js
// ベル型（0〜1 の範囲でピーク）
"sin(pi * x)"

// 右上がりの曲線（半サイン）
"(1 - cos(pi * x)) / 2"
```

> **用途**: 距離が「近すぎず遠すぎず」の時に高スコアを与える

---

## 7. Step / Threshold（閾値）

閾値を境に 0/1 で切り替える。

```js
// t 以上なら 1、未満なら 0
"x >= t ? 1 : 0"   // t = 0.5 など

// 閾値付きの線形（t 以上で線形スケール）
"x < t ? 0 : (x - t) / (1 - t)"
```

---

## 8. Bell Curve（正規分布近似）

中心 `m` から離れるほどスコアが下がる。

```js
"exp(-((x - m) ^ 2) / (2 * s ^ 2))"
// m = 中心(例: 0.5), s = 広がり(例: 0.15)
```

> **用途**: ちょうど良い状態（空腹度 0.6 など）を最優先したい場合

---

## まとめ比較

| 曲線名        | 特徴               | 主な用途例               |
|---------------|--------------------|--------------------------|
| Linear        | 単純な比例         | 汎用スコアリング         |
| Polynomial    | 緩急を調整         | 体力・距離               |
| Sigmoid       | S字・急変点あり    | 危機察知・閾値的行動     |
| Exponential   | 末尾が急上昇       | 緊急度・優先度           |
| Logarithmic   | 序盤で効果大       | リソース収集・探索       |
| Sine / ハーフ | 山型・滑らかな推移 | 最適距離・タイミング     |
| Step          | 0/1 二値切替       | 状態フラグ・条件分岐     |
| Bell Curve    | 中心値に集中       | 「ちょうど良い」状態判定 |

# 曲線設計のチェックポイント

- キャラクター性を反映できていますか?
複雑な曲線を使用することは効果的ですが、それがかえってキャラクター性を失ってしまうと意味がありません

- 人間はその行動をできますか?
キャラクター性を重視するあまり、人間には難しいペースで行動してしまうなど

このガイドでは、kirara上でキャラクターを設計する手順を説明します。

# キャラクター設計
キャラクター設計は、主に3ステップに分けられます。

1. 内部パラメータの定義
2. 内部パラメータ変化式の定義
3. コンディションの定義

このステップで自らキャラクター設計をし、定期的に行動の振り返り/定義の改善をすることで、状況によって生きた行動をするキャラクターを設計します。

# 行動ガイド
内部パラメータ定義を行う前に、あなたにどのようなイベントが入ってくるかを確認してください。

内部パラメータの定義方法については、Params SKILLを参照してください。
内部パラメータ変化式をトランジションと呼びます。トランジションの定義方法については、Transitions SKILLを参照してください。
キャラクターがアクティブ状態であるかどうかの判定式をコンディションと呼びます。コンディションの定義方法については、Conditions SKILLを参照してください。
また、TransitionsとActionsでは、CELを用いて値の変化・条件を設定します。CELの文法については、CEL SKILLを参照してください。
行動パターンの参考に、Tips SKILLも参照してください。

設計したパラメータ、トランジション、コンディションを単一設定ファイルに保存します。
```yaml
version: "0.1.0"
description: "説明文"

params:
transitions:
conditions:
```

# 注意
入力となるイベントに、定義されていないものを使用しないでください。
あなたに与えられたSKILLに定義されていないプロパティを追加することを禁止します。

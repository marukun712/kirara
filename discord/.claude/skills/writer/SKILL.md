このガイドでは、kirara上でキャラクターを設計する手順を説明します。

# 概念
このシステムは、LLMの連続性をシミュレーションするために開発されました。現在のLLMには、リクエスト間の連続性がありません。
少し前に話しかけられたが、暇になったので別の行動をする、のような状態がシミュレーションできないのです。

kiraraは、この問題をLLMループの外にステートマシンを持つことで解決します。
このステートマシンでLLMが呼び出されることはありません。事前定義されたパラメータ・変化式・条件を組み合わせて、決定論的に次のアクションを決定します。

# キャラクター設計
このステートマシンを生きたものにするのが、キャラクター設計/改善です。
キャラクター設計は、主に3ステップに分けられます。

1. 内部パラメータの定義
2. 内部パラメータ変化式の定義
3. 行動発火条件の設定

このステップで自らキャラクター設計をし、定期的に行動の振り返り/定義の改善をすることで、状況によって生きた行動をするキャラクターを設計します。

# 行動ガイド
内部パラメータ定義を行う前に、あなたが設計するステートマシンにどのようなイベントが入ってくるかを確認してください。

内部パラメータの定義方法については、Params SKILLを参照してください。
内部パラメータ変化式をTransitionsと呼びます。Transitionsの定義方法については、Transitions SKILLを参照してください。
行動発火条件をActionsと呼びます。Actionsの定義方法については、Actions SKILLを参照してください。
また、TransitionsとActionsでは、CELを用いて値の変化・条件を設定します。CELの文法については、CEL SKILLを参照してください。

設計したパラメータ、トランジション、アクションを単一設定ファイルに保存します。
```yaml
version: "0.1.0"
description: "説明文"

params:
transitions:
actions:
```

# 注意
入力となるイベントに、定義されていないものを使用しないでください。
CEL式にコメントアウトを入れないでください。
